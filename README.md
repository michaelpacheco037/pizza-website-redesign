# Roma’s Pizza & Italian Restaurant

A responsive restaurant website built with **HTML, CSS, JavaScript, and PHP**. The site presents Roma’s menu, restaurant story, promotions, and contact information through a consistent, multi-page design.

## Technologies

- **HTML:** Page structure, menu content, and form elements.
- **CSS:** Styling, typography, and responsive layouts using Flexbox, Grid, and media queries.
- **JavaScript:** Mobile navigation, image carousels, form validation, and cart interactions.
- **PHP:** Shared navigation and footer content across pages.

## Features

- Home, About, Promotions, Contact, and Menu pages
- Menu organized into food categories with images and prices
- Demo cart with quantity controls, item removal, and subtotal calculations
- Contact form with validation and a confirmation page
- Promotional and customer-review carousels
- Google Maps integration and restaurant contact links

## Design

The design combines dark backgrounds, warm cream text, and red and green accents inspired by the Italian flag. Food imagery, custom branding, and promotional graphics establish the restaurant’s identity, while serif headings and consistent spacing organize the content.

Responsive layouts adapt the navigation, menu cards, and page sections for desktop, tablet, and mobile screens.

## Project Notes

This is a demonstration website. The cart does not place orders or process payments, and the contact form does not send messages.
