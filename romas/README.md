# Roma’s Pizza Website Redesign

A responsive restaurant website built with **HTML, CSS, JavaScript, and PHP**. Originally created by **Michael Pacheco and Reed Turner** for the 2024 CTEC 4309 Internet Marketing term project.

## Features

- Home, About, Promotions, Contact, and Menu pages
- Shared PHP navigation and footer
- Responsive layouts and a mobile menu
- Manually controlled image carousels
- Demo cart with quantity controls, item removal, and a subtotal
- Contact form validation and a demo confirmation page

## Run Locally

This project needs a PHP server. Opening the PHP files directly or using a static HTML server will not render the shared navigation and footer.

With PHP installed, open a terminal in this folder and run:

```sh
php -S localhost:8000
```

Then visit **http://localhost:8000** in your browser. Keep the `images` folder and all project files together.

## Project Notes

This is a portfolio demonstration. The cart does not process payments or place orders, and the contact form does not save or email messages. Menu prices, hours, and promotional artwork come from the original project and may be outdated.

The contact page includes a Google Maps embed. No frontend framework, package installation, or build step is required.
